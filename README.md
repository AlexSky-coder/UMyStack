Описание и применение класса `tStackFan<TData>`

Этот универсальный класс реализует стек (LIFO‑структуру: *Last In, First Out*) с динамическим управлением памятью. Ниже — детальное руководство по использованию.
1. Назначение и ключевые особенности
Зачем нужен этот класс?
Для эффективного хранения и обработки данных в порядке «последний пришёл — первый вышел», с автоматической регулировкой объёма памяти.

Главные преимущества:
- Универсальность: работает с любым типом `TData` (числа, строки, объекты, интерфейсы).
- Автоматическое управление памятью: массив расширяется при заполнении и сжимается при низком использовании.
- Безопасность: методы `Try...` не вызывают исключений.
- Прямой доступ: возможность чтения элементов по индексу (`peekAt`).
- Оптимизация: сжатие массива при занятости < 25 % ёмкости.

2. Базовое использование
2.1. Создание стека для конкретного типа

Используйте `specialize` для генерации класса под нужный тип:
```pascal
type
  TStackBool = specialize tStackFan<boolean>;
  TStackInt = specialize tStackFan<int64>;
  TStackReal = specialize tStackFan<double>;
  TStackStr = specialize tStackFan<string>;    
```

2.2. Инициализация и освобождение

```pascal
var
Stack: TStackInt;
begin
Stack := TStackInt.Create;// Создание пустого стека
// ... работа со стеком ...
Stack.Free;// Освобождение ресурсов (вызывает Destroy)
end;
```
3. Основные операции
3.1. Добавление элемента
```pascal
Stack.push(42);// Добавляет 42 в вершину стека
```
- Если массив заполнен, его размер удваивается (минимум до 8 элементов).

3.2. Извлечение элемента

С проверкой на пустоту (безопасный вариант):
```pascal
var
Value: int64;
begin
if Stack.TryPop(Value) then
WriteLn('Извлечено: ', Value)
else
WriteLn('Стек пуст');
end;
```

С исключением (требует обработки ошибок):
```pascal
try
Value := Stack.pop;
WriteLn('Извлечено: ', Value);
except
on E: Exception do WriteLn('Ошибка: ', E.Message);
end;
```

3.3. Просмотр верхнего элемента

Безопасный вариант:
```pascal
if Stack.TryPeek(Value) then
WriteLn('Верхний элемент: ', Value);
```
С исключением:
```pascal
Value := Stack.peek;// Может вызвать EStackEmpty
```
3.4. Доступ по индексу
Безопасный вариант:
```pascal
if Stack.TryPeekAt(0, Value) then// Первый элемент
WriteLn('Элемент [0]: ', Value);
```

С исключениями:
```pascal
Value := Stack.peekAt(2);// Третий элемент (индекс 2)
// Может вызвать EStackEmpty или EIndexOutOfRange
```

4. Вспомогательные методы

4.1. Проверка состояния
```pascal
if Stack.isEmpty then ...// Пуст ли стек?
Count := Stack.size;// Количество элементов
Capacity := Stack.GetCapacity;// Текущая ёмкость массива
LastIdx := Stack.getLastIndex; // Индекс верхнего элемента (-1, если пуст)
```

4.2. Управление памятью
```pascal
Stack.Reserve(100); // Гарантирует ёмкость ≥ 100 элементов
Stack.removeUnnecessaryItems;// Урезает массив до фактического размера
Stack.Clear; // Очищает стек (обнуляет элементы, сбрасывает индексы)
```

4.3. Сжатие массива

Автоматически вызывается после `pop` и `TryPop`, если:
- Длина массива > 32.
- Занято < 25 % ёмкости (`FTopIndex + 1 < Length(FItems) div 4`).

Новая длина: `max(Length(FItems) div 2, 8)`.

5. Примеры сценариев

5.1. Обработка последовательности чисел
```pascal
var
Stack: TStackInt;
Value: int64;
begin
Stack := TStackInt.Create;
Stack.push(10);
Stack.push(20);
Stack.push(30);

while not Stack.isEmpty do
begin
Value := Stack.pop;
WriteLn(Value);// Выведет: 30, 20, 10
end;

Stack.Free;
end;
```

5.2. Безопасная работа с неизвестным содержимым
```pascal
if Stack.TryPeek(Value) then
WriteLn('Вершина стека: ', Value)
else
WriteLn('Стек пуст, действий не требуется');
```

5.3. Итерация по элементам
```pascal
for i := 0 to Stack.size - 1 do
begin
if Stack.TryPeekAt(i, Value) then
WriteLn('Элемент [', i, ']: ', Value);
end;
```

6. Важные замечания

1. Управляемые типы (строки, интерфейсы):
 - При `Clear` элементы обнуляются автоматически.
 - При `FastPop` ячейка устанавливается в `Default(TData)`.

2. Производительность:
 - Методы `Fast...` (например, `FastPop`) не проверяют границы — используйте их только при гарантии корректности индексов.
 - `Try...` методы чуть медленнее из‑за проверок, но безопаснее.

3. Исключения:
 - `pop`, `peek`, `peekAt` могут вызывать:
 - `EStackEmpty` — стек пуст.
 - `EIndexOutOfRange` — неверный индекс (для `peekAt`).

4. Память:
 - `Reserve` позволяет заранее выделить память, если известно примерное количество элементов.
 - `removeUnnecessaryItems` полезен перед длительной работой без изменений размера.

---

7. Типичные ошибки и как их избежать

- Не проверять `isEmpty` перед `pop`/`peek` → используйте `TryPop`/`TryPeek`.
- Выходить за границы индекса → проверяйте `size` перед `peekAt`.
- Забывать освобождать память → всегда вызывайте `Free` для экземпляра стека.
- Игнорировать ёмкость → используйте `Reserve`, если ожидается много элементов.

Класс `tStackFan<TData>` — мощный инструмент для работы со стеками в Free Pascal. Он сочетает безопасность, гибкость и оптимизацию памяти, подходя как для простых задач, так и для сложных сценариев с большими объёмами данных.
